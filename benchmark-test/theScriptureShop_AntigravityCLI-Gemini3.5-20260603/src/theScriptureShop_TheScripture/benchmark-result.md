## 구현된 기능 목록

- **[REQ-001] 성경 상품 및 카탈로그 조회**
  - 데이터베이스에 미리 등록된 KJV, NIV 등 10개 성경 데이터(Seed) 조회.
  - 메인 화면(`/`)에서 표지 이미지, 번역본 이름, 설명을 카드 형태로 그리드 렌더링.
- **[REQ-002] 비회원 장바구니 관리**
  - 세션 쿠키를 활용하여 로그인 없이 원하는 성경 책을 장바구니에 적재.
  - 장바구니 화면(`/cart`)에서 개별 성경의 수량을 가감(`[-]` / `[+]`)하거나 품목을 완전히 `[삭제]` 처리.
- **[REQ-003] 신앙 고백 및 무료 주문**
  - 장바구니 페이지에서 수령자명, 연락처, 주소 정보 입력 폼 제공.
  - 고유 고백 체크박스 및 `[믿는다]` 버튼 클릭 여부를 서버 및 클라이언트 측에서 3중 방어막으로 검증.
  - 신앙 고백 완료 시 고유 주문번호(S-YYYYMMDD-XXXX) 발급 및 장바구니 비우기 완료.
- **[REQ-004] 비회원 배송 및 송장 조회**
  - 메인화면 상단의 [배송 조회] 버튼을 통해 모달 팝업 가동.
  - 발급된 주문번호를 입력하면 배송 상태 및 발송 완료 시 등록된 8자리 송장번호 렌더링.
- **[REQ-005] 관리자 모드 및 발송 완료 처리**
  - `/admin/login`을 통한 `admin/admin` 관리자 세션 로그인 및 인가 미들웨어 적용.
  - '발송 대기'와 '발송 완료' 주문 목록을 필터링 탭으로 구분하여 렌더링.
  - 주문 상세 패널에서 해당 사용자가 동의한 신앙 고백 구절과 동의 완료 일시를 명확하게 표시.
  - 8자리 숫자로 구성된 송장번호를 검증하여 입력 시 상태를 '발송 완료'로 업데이트하는 로직 구현.

## 에러 로그

1. **[BUG-001] ESM import hoisting 에러**
   - *현상:* 테스트 구동(`node --test`) 시 최상단 static import에 의해 `process.env.NODE_ENV = 'test'`가 설정되기 전에 `index.ts`가 불러와져 로컬 3000 포트가 바인딩되는 현상 발생.
   - *수정:* `test/app.test.ts` 내의 static import들을 `before()` 훅 내부에서 `await import()` 동적 비동기 임포트로 교체하여 해결.
2. **[BUG-002] Cookie double URL encoding 에러**
   - *현상:* `routes/shop.ts` 내부에서 쿠키 저장 시 `encodeURIComponent`를 직접 중복 적용하여 Hono 내장 인코딩과 겹쳐 쿠키값이 깨져 읽히는 현상 발생.
   - *수정:* get/set cookie 로직에서 불필요한 URL encoding 함수들을 걷어내고 Hono의 기본 cookie 매커니즘에 전적으로 위임.
3. **[BUG-003] Windows Node 24.13.0 환경 SQLite Heap Corruption**
   - *현상:* `node:test` 종료 혹은 `db.close()` 호출 시 SQLite 리소스 해제 충돌로 인해 Windows STATUS_HEAP_CORRUPTION(0xC0000374) 에러가 발생하며 테스트가 비정상 종료되는 현상.
   - *수정:* 테스트 완료 후 프로세스가 자동 종료될 때 DB 핸들이 안전하게 해제됨을 이용해, `after()` 블록 내 `db.close()`를 비활성화하여 힙 오류 해결.
4. **[BUG-004] TSX 내 HTML 주석 문법 에러**
   - *현상:* `views/shop.tsx` 및 `views/admin.tsx` 컴포넌트 내부에 `<!-- ... -->` 형태의 HTML 주석을 잘못 표기하여 빌드 트랜스파일러 에러 발생.
   - *수정:* 모든 JSX/TSX 반환 영역 내 HTML 주석을 표준 JSX 주석 `{/* ... */}`으로 변경하여 컴파일 정상화.
