## 2. 목적 (Purpose)

비회원을 대상으로 무료로 성경(KJV, NIV 등 10개 번역본)을 배포하는 쇼핑몰 웹 애플리케이션을 구축한다. 
장바구니와 비회원 배송지 정보 입력, 그리고 가장 핵심적인 '신앙 고백(믿음의 동의)'을 거쳐 무료 주문을 완료하게 하며, 관리자가 송장번호를 입력하여 발송 처리를 수행하는 비즈니스 흐름을 온전히 구현한다.

## 6. 범위 (Scope)

### 포함
- 10개의 성경 책 목록(Seed 데이터) DB 영속화 및 메인 화면 카드 렌더링
- 세션 기반 비회원 장바구니(추가, 수량 변경, 삭제)
- 주소 입력, 신앙 고백 체크박스 동의, `[믿는다]` 클릭을 통한 주문 생성 및 고유 주문번호(UUID 또는 고유 포맷) 발급
- 주문번호 기반의 실시간 배송 조회 및 송장번호 표시
- `admin` / `admin` 계정을 이용한 관리자 세션 로그인 및 로그아웃
- 관리자용 상태별 주문 목록, 상세 정보(신앙고백 합격 내역 포함) 조회
- 관리자용 8자리 숫자 송장번호 발송 완료 처리 기능

### 제외
- 일반 사용자 회원가입 및 로그인 (비회원 전용)
- PG 결제 연동 및 계좌이체 확인 로직 (모든 성경은 무료 배포)
- 10개 기본 성경 외의 상품 동적 추가/수정/삭제 기능 (Admin용 상품 관리 제외)
- 이메일/알림톡 발송 기능 (화면 조회로 대체)

## 8. 완료 기준 (Done Criteria)

- [ ] 메인 페이지 접속 시 KJV, NIV 등 10개의 성경 Seed 데이터 카드 목록이 정상 렌더링된다.
- [ ] 성경을 장바구니에 담고 수량 조절 및 삭제가 정상적으로 수행된다. (총 가격 계산은 미표시)
- [ ] 장바구니에서 [주문하기] 클릭 시 주소 입력 폼과 신앙 고백 체크박스 및 `[믿는다]` 버튼이 표시된다.
- [ ] 신앙 고백 체크박스 해제 상태에서 `[믿는다]` 버튼 클릭 시 주문이 거부되고 경고가 표시된다.
- [ ] 신앙 고백 체크박스 선택 후 `[믿는다]` 클릭 시 주문이 완료되고, 화면에 고유 주문번호가 생성되어 표시된다.
- [ ] 메인 화면의 [배송 조회] 버튼을 통해 발급된 주문번호를 입력하면 주문 상품, 주소, 상태, 송장번호가 조회된다.
- [ ] `/admin` 주소로 접근 시 로그인 폼이 제공되며, `admin`/`admin` 입력 시 관리자 페이지에 진입한다. 비인증 접근은 차단된다.
- [ ] 관리자 페이지에서 주문 상태(발송 대기/발송 완료)별 필터링이 정상 동작한다.
- [ ] 관리자 주문 상세에서 주문자가 신앙 고백에 동의했다는 문구("예수님을 나의 구원자로 믿고...")와 동의 일시/여부가 명확하게 표시된다.
- [ ] 관리자가 8자리 숫자가 아닌 송장번호 입력 시 유효성 에러가 발생하며 발송 처리가 되지 않는다.
- [ ] 관리자가 8자리 숫자 송장번호 입력 후 `[발송처리]` 클릭 시 주문 상태가 '발송 완료'로 업데이트된다.
- [ ] 모든 소스코드는 `fruit-열매/` 폴더에 구현되며 빌드 오류 없이 `npm run dev`로 원활히 실행된다.
