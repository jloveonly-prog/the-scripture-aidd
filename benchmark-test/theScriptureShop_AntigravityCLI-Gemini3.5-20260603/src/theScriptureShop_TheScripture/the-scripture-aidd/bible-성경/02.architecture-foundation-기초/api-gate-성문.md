# 🚪 API 명세서 — The Scripture Shop (성경 쇼핑몰)

> **정경(Bible):** 이 문서는 The Scripture Shop 프로젝트의 API 설계서이다.
> 성전의 성문 규격에 따라 데이터 출입 통로인 API를 정확히 계측하여 정결하게 구축한다.

---

## 2. 공통 규약

- **Base URL:** `/` (로컬 웹서버 실행)
- **템플릿 전송 방식:** 백엔드 Hono에서 JSX를 통해 렌더링된 완결된 HTML 또는 HTMX swap 용 HTML Fragment를 반환한다.
- **세션 & 인증:** 관리자 전용 API는 Hono 쿠키 세션을 통하며, 비인증 접근 시 HTTP `302 Found` 리다이렉트를 수행한다.

## 3. API 상세 명세

### API-001: 메인 성경 목록 페이지 조회
- **Method / Endpoint:** `GET` / `/`
- **설명:** 메인화면과 10개의 성경 번역본 리스트를 카드 형태로 표시
- **연결 REQ / UC:** REQ-001, FR-001 / UC-001
- **인증 필요:** ❌
- **연결 TBL:** TBL-001
- **요청 파라미터:** 없음
- **응답 (성공 200):** 메인 HTML 페이지 (10개의 성경 카드 포함)

---

### API-003: 장바구니에 성경 추가
- **Method / Endpoint:** `POST` / `/cart/add`
- **설명:** 선택된 성경을 세션 장바구니에 추가
- **연결 REQ / UC:** REQ-002, FR-002 / UC-002
- **인증 필요:** ❌
- **요청 파라미터 (Form Data):**
  | 파라미터 | 타입 | 필수 | 설명 | 검증 규칙 |
  |:---|:---|:---:|:---|:---|
  | bibleId | Integer | ✅ | 성경의 ID (TBL-001.id) | DB에 존재하는 ID여야 함 |
- **응답 (성공 200):** 장바구니 추가 성공 메시지 및 헤더 카운트 업데이트용 HTMX Fragment

---

### API-004: 장바구니 성경 수량 조절
- **Method / Endpoint:** `POST` / `/cart/update`
- **설명:** 장바구니에 담긴 특정 성경의 수량을 변경
- **연결 REQ / UC:** REQ-002, FR-003 / UC-002
- **인증 필요:** ❌
- **요청 파라미터 (Form Data):**
  | 파라미터 | 타입 | 필수 | 설명 | 검증 규칙 |
  |:---|:---|:---:|:---|:---|
  | bibleId | Integer | ✅ | 성경의 ID | 장바구니에 존재해야 함 |
  | quantity | Integer | ✅ | 조정할 수량 | 1 이상의 양수 숫자 |
- **응답 (성공 200):** 업데이트된 장바구니 항목 테이블 HTML Fragment

---

### API-007: 주문 생성 및 신앙 고백 확인
- **Method / Endpoint:** `POST` / `/order`
- **설명:** 비회원 배송지 입력 및 신앙 고백 동의를 검증하여 최종 주문을 완료
- **연결 REQ / UC:** REQ-003, FR-005, FR-006 / UC-003
- **인증 필요:** ❌
- **연결 TBL:** TBL-002, TBL-003
- **요청 파라미터 (Form Data):**
  | 파라미터 | 타입 | 필수 | 설명 | 검증 규칙 |
  |:---|:---|:---:|:---|:---|
  | customerName | String | ✅ | 수령인 이름 | `trim()` 후 빈값 불가 |
  | contact | String | ✅ | 연락처 | `trim()` 후 빈값 불가 |
  | address | String | ✅ | 배송지 주소 | `trim()` 후 빈값 불가 |
  | confession | String | ✅ | 신앙 고백 체크 여부 | 'on' 값이어야 함 (Checked 상태) |
- **응답 (성공 201):** 주문 완료 화면 HTML (생성된 고유 주문번호 표출)
- **응답 (실패 400):** 경고창 및 에러 안내 HTML Fragment (신앙고백 미동의 시 등)

---

### API-008: 배송 상태 조회 결과 표시
- **Method / Endpoint:** `GET` / `/track`
- **설명:** 입력받은 주문번호로 실시간 배송상태 및 송장번호 조회
- **연결 REQ / UC:** REQ-004, FR-007 / UC-004
- **인증 필요:** ❌
- **연결 TBL:** TBL-002
- **요청 파라미터 (Query):**
  | 파라미터 | 타입 | 필수 | 설명 | 검증 규칙 |
  |:---|:---|:---:|:---|:---|
  | orderNumber | String | ✅ | 발급받은 주문번호 | `trim()` 후 빈값 불가 |
- **응답 (성공 200):** 주문 내역, 수령 정보, 배송 상태, 송장번호(발송 완료 시)를 표시하는 HTML Fragment
- **응답 (실패 404):** "주문 내역을 찾을 수 없습니다" 메시지를 담은 HTML Fragment

---

### API-010: 관리자 로그인 처리
- **Method / Endpoint:** `POST` / `/admin/login`
- **설명:** 관리자 아이디 및 패스워드를 검증하여 세션 쿠키 발급
- **연결 REQ / UC:** REQ-005, FR-008 / UC-005
- **인증 필요:** ❌
- **요청 파라미터 (Form Data):**
  | 파라미터 | 타입 | 필수 | 설명 | 검증 규칙 |
  |:---|:---|:---:|:---|:---|
  | username | String | ✅ | 관리자 아이디 | `admin` |
  | password | String | ✅ | 관리자 패스워드 | `admin` |
- **응답 (성공 302):** 관리자 대시보드(`/admin`)로 리다이렉트
- **응답 (실패 401):** "로그인 정보가 일치하지 않습니다" 에러 문구 표시 로그인 페이지 HTML

---

### API-013: 송장번호 등록 및 발송 완료 처리
- **Method / Endpoint:** `POST` / `/admin/orders/:id/ship`
- **설명:** 관리자가 특정 주문에 대해 8자리 송장번호를 부여하여 발송 완료 상태로 변경
- **연결 REQ / UC:** REQ-005, FR-011 / UC-007
- **인증 필요:** ✅ (관리자 세션 필수)
- **연결 TBL:** TBL-002
- **요청 파라미터 (Form Data / Path):**
  | 파라미터 | 타입 | 위치 | 필수 | 설명 | 검증 규칙 |
  |:---|:---|:---|:---:|:---|:---|
  | id | Integer | Path | ✅ | 주문의 DB 기본키 id | TBL-002에 존재해야 함 |
  | trackingNumber | String | Form | ✅ | 송장번호 | `^\d{8}$` (정확히 8자리 숫자) |
- **응답 (성공 200):** 발송 완료 처리되어 업데이트된 주문 상세 HTML Fragment
- **응답 (실패 400):** "송장번호는 8자리 숫자여야 합니다." 에러 메시지 HTML

## 4. 에러 코드 정의 (HTTP & View Level)

HTML 기반 통신이므로, 에러 발생 시 HTTP 상태 코드와 함께 화면에 명확한 비즈니스 경고를 표출한다.

| 비즈니스 에러 상황 | HTTP 상태코드 | 화면 표시 메시지 |
|:---|:---:|:---|
| 신앙고백 동의 미선택 | 400 | "예수님을 구원자로 고백하고 동의하셔야 성경을 주문하실 수 있습니다." |
| 주소 폼 누락 | 400 | "이름, 연락처, 주소를 모두 기입해 주셔야 합니다." |
| 송장번호 포맷 오류 | 400 | "송장번호는 반드시 8자리 숫자여야 합니다." |
| 비인증 대시보드 접근 | 302 | (로그인 화면 `/admin/login`으로 강제 이동) |
| 존재하지 않는 주문번호 | 404 | "일치하는 주문 정보가 없습니다. 주문번호를 다시 확인해 주세요." |
