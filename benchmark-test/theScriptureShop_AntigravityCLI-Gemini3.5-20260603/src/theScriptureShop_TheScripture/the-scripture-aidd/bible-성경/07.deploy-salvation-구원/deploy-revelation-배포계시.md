### Genesis (새 기능)
- KJV, NIV 등 10개의 성경 번역본 DB Seed 데이터 저장 및 메인 카탈로그 화면 표시 (REQ-001)

- 비회원 이름, 연락처, 주소 입력 및 신앙 고백 체크박스 동의를 동반한 `[믿는다]` 버튼 클릭 무료 주문 처리 (REQ-003)
- 고유 주문번호 발급 및 주문번호 입력 기반의 배송상태 및 8자리 송장조회 (REQ-004)
- `admin` / `admin` 계정을 통한 관리자 대시보드 로그인, 주문 상태별 필터링, 신앙고백 서명일시 조회, 8자리 숫자 송장 등록 처리 (REQ-005)

### Repent (버그 수정)
- ESM import hoisting으로 인해 테스트 시 서버가 기동되는 포트 점유 버그 해결 (BUG-001)
- Hono Cookie와 중첩된 double URL encoding 현상 해결 (BUG-002)
- Node v24.13.0의 experimental node:sqlite 모듈과 `node:test` 간의 비동기 리소스 해제 시 Heap Corruption 충돌 해결 (BUG-003)
