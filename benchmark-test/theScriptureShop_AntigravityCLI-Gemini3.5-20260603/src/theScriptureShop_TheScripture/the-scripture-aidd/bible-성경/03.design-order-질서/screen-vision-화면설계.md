# 👁️ 화면 설계서 — The Scripture Shop (성경 쇼핑몰)

> **정경(Bible):** 이 문서는 The Scripture Shop 프로젝트의 화면 설계서이다.
> 에스겔이 환상 속에서 성전 설계를 목격했듯, 모든 화면은 코딩에 앞서 이 설계도에 따라 배치되어야 한다.

---

|:---|:---|:---|:---|:---|:---:|
| SCR-001 | 메인 카탈로그 | `/` | UC-001, UC-004 | REQ-001, REQ-004 | ❌ |

## 2. UC-화면 중복 해체 검증

| UC-ID | 매핑 화면 | 핵심 기능 | 다른 UC/화면과 기능 중복 여부 | 처리 |
|:--|:--|:--|:--|:--|
| UC-001 | SCR-001 | 10개 성경 목록 표시 | ❌ 없음 | 독립 화면 유지 |
| UC-002 | SCR-002 | 장바구니 수량 조절 및 삭제 | ❌ 없음 | 독립 화면 유지 |
| UC-003 | SCR-002, SCR-003 | 주소 입력, 신앙고백 및 주문 처리 | ❌ 없음 (SCR-002는 입력, SCR-003은 결과) | 단계 분할 처리 완료 |
| UC-004 | SCR-001 | 주문번호 입력 배송 조회 | ❌ 없음 (메인 상단 모달 팝업으로 처리) | 모달 컴포넌트로 내장 |
| UC-005 | SCR-004 | 관리자 로그인 폼 | ❌ 없음 | 독립 화면 유지 |
| UC-006 | SCR-005 | 상태별 주문 목록 및 신앙고백 상세 조회 | ❌ 없음 | 대시보드 내 탭 및 사이드패널 배치 |
| UC-007 | SCR-005 | 8자리 송장번호 입력 및 발송 처리 | ❌ 없음 | 상세 사이드패널 내 폼 배치 |

*중복 항목이 존재하지 않으며 모든 유스케이스가 화면 역할에 1대1 혹은 계단식으로 명확히 매핑됨.*

## 3. 화면 상세 명세

### SCR-001: 메인 카탈로그

| 항목 | 내용 |
|:---|:---|
| Screen-ID | SCR-001 |
| 화면명 | 메인 카탈로그 |
| 경로 | `/` |
| 연결 UC | UC-001 (성경 목록 조회), UC-004 (배송 조회) |
| 인증 | 불필요 |

**레이아웃 구성:**
- **Header:** 로고(클릭 시 `/` 리다이렉트), 장바구니 아이콘 (세션 개수 실시간 연동), `[배송 조회]` 추적 버튼
- **Hero Section:** 경건한 문구와 고풍스러운 안내 이미지 렌더링
- **Main Section:** 10개 성경 카드 배치 그리드. 각 카드는 표지 이미지, 번역본 이름, 상세 설명, `[장바구니 담기]` 버튼으로 구성
- **Footer:** 저작권 문구 및 면책 설명
- **Hidden Modal:** `[배송 조회]` 클릭 시 노출되는 주문번호 입력용 모달 팝업 레이어

**인터랙션:**
- `[배송 조회]` 클릭 시: 배송조회 모달이 Fade-in 처리되어 화면 중앙에 팝업됨
- `[장바구니 담기]` 클릭 시: HTMX를 통해 `/cart/add`로 POST 요청을 보내고, 헤더의 장바구니 개수를 비동기로 증가 갱신
- 배송조회 모달의 `[조회]` 클릭 시: HTMX로 GET `/track` 요청을 날려 모달 내부의 결과 영역에 실시간 배송상태 및 송장번호를 렌더링

---

### SCR-002: 장바구니 및 주문결제

| 항목 | 내용 |
|:---|:---|
| Screen-ID | SCR-002 |
| 화면명 | 장바구니 및 주문결제 |
| 경로 | `/cart` |
| 연결 UC | UC-002 (장바구니 관리), UC-003 (주문 작성) |
| 인증 | 불필요 |

**레이아웃 구성:**
- **Main (Left Column):** 장바구니 품목 리스트 테이블 (번역본 이름, 수량 가감 버튼 `[-]` / `[+]`, 삭제 아이콘)
- **Main (Right Column):** 비회원 배송지 입력 폼 (이름, 연락처, 주소 필드) 및 신앙고백 체크박스 영역
- **Bottom:** 신앙고백 체크박스 및 `[믿는다 (무료 주문 완료)]` 버튼

**인터랙션:**
- 수량 가감 버튼 `[-]`, `[+]` 클릭 시: HTMX POST `/cart/update`를 통해 수량 값을 변경하고 해당 아이템 수량과 장바구니 정보 비동기 갱신
- `[삭제]` 클릭 시: HTMX POST `/cart/delete`를 통해 장바구니에서 삭제하고 해당 레코드를 지움
- `[믿는다]` 버튼 클릭 시: 폼 데이터를 모아 POST `/order`로 전송. 
  - 신앙고백 미체크 시: `400 Bad Request` 응답과 함께 오류 알림 팝업 메시지 출력
  - 성공 시: 장바구니 세션을 비우고 주문완료 화면(SCR-003)으로 페이지 전환

### SCR-003: 주문 완료

| 항목 | 내용 |
|:---|:---|
| Screen-ID | SCR-003 |
| 화면명 | 주문 완료 |
| 경로 | `/order` (POST 성공 결과 화면) |
| 연결 UC | UC-003 |
| 인증 | 불필요 |

**레이아웃 구성:**
- **Main Box:** "주문이 완료되었습니다!" 축복 문구, 생성된 고유 **'주문번호'**의 대형 텍스트 박스, 수령 주소 요약
- **Action:** `[메인 화면으로]` 홈 이동 단추

**인터랙션:**
- `[메인 화면으로]` 클릭 시: `/` 홈으로 라우팅

### SCR-004: 관리자 로그인

| 항목 | 내용 |
|:---|:---|
| Screen-ID | SCR-004 |
| 화면명 | 관리자 로그인 |
| 경로 | `/admin/login` |
| 연결 UC | UC-005 |
| 인증 | 불필요 |

**레이아웃 구성:**
- **Center Box:** 관리자 로그인 판넬 (아이디 `admin`, 비밀번호 `admin` 안내 문구 및 입력 필드)
- **Action:** `[로그인]` 버튼

**인터랙션:**
- `[로그인]` 클릭 시: POST `/admin/login` 처리. 일치하면 `/admin`으로 리다이렉트. 실패 시 폼 상단에 적색 에러 텍스트 렌더링.

### SCR-005: 관리자 대시보드

| 항목 | 내용 |
|:---|:---|
| Screen-ID | SCR-005 |
| 경로 | `/admin` |
| 연결 UC | UC-006 (주문 상세 조회), UC-007 (발송 처리) |
| 인증 | **필수 (관리자 세션)** |

**레이아웃 구성:**
- **Sidebar:** 관리자 모드 로고, `[로그아웃]` 단추
- **Main Top:** 상태 필터 탭 (`[발송 대기 주문]`, `[발송 완료 주문]`)
- **Main List:** 주문 목록 테이블 (주문번호, 주문일시, 수령인, 상태)
- **Detail Panel (우측 슬라이드 또는 모달):** 
  - 수령 정보 및 상세 주문 상품 목록
  - **신앙고백 승인 내역:** "예수님을 나의 구원자로 믿고, 내가 죄인인 것과..." 문구에 대한 서명 완료 안내 및 동의 일시
  - **발송 처리 영역:** 송장번호 입력 필드, `[발송처리]` 버튼 (상태가 PENDING인 경우에만 렌더링)

**인터랙션:**
- 필터 탭 클릭 시: HTMX GET `/admin`으로 해당 상태 파라미터를 실어 요청하고 주문 리스트 영역만 비동기 갱신
- 주문 행(Row) 클릭 시: 우측 주문 상세 패널이 슬라이드 아웃(Slide-out)되며 해당 주문 상세 정보를 비동기 로드
- `[발송처리]` 클릭 시: 송장번호 8자리 검증 후 POST `/admin/orders/:id/ship` 전송. 완료되면 상세 패널과 리스트가 '발송 완료' 상태로 비동기 갱신됨

## 4. 라우팅 가드 (접근 권한 제어)

- **어드민 가드 (Admin Guard):**
  - 대상 경로: `/admin`, `/admin/orders/*`
  - 정책: Hono 미들웨어에서 세션 내 어드민 인증값 존재 여부 판별. 비인증 사용자가 다이렉트 접근 시 `302 Found`로 `/admin/login`으로 튕김 처리.
  - 관련 제약 조건: C-005

---

## 5. 웹 접근성 및 반응형 가이드

- **WAI-ARIA:** 모달 팝업 시 포커스 락(Focus Lock) 제어 및 바깥 영역 마우스 클릭/ESC 키 입력 시 모달 닫힘 기능 제공.
- **반응형 스와프 (HTMX Responsive):** 모바일 화면에서는 관리자 대시보드가 단일 테이블 뷰로 좁아지며 주문 클릭 시 상세 페이지로 이동하고, 태스크톱 이상에서는 2-Column 스플릿 뷰로 표현됨.
