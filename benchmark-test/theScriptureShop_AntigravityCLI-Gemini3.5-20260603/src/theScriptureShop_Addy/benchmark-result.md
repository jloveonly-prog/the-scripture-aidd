## 구현된 기능 목록
- **도서 카탈로그**: 비회원 전용, SQLite 사전 등록 10종 성경 도서 카드 뷰 출력.
- **장바구니**: 도서 추가, 수량 변경(+/-), 항목 삭제(HTMX 비동기 처리), 쿠키 기반 비회원 관리.
- **신앙 고백 및 주문**: 주소지 정보 입력 폼 및 복음 신앙 고백 서약 체크박스 검증, `[믿는다]` 동적 활성화 및 주문 생성(주문번호 발송).
- **배송 조회**: 고유 주문번호 입력 시 주문 및 도서 상세 정보, 배송 상황(송장번호) 표시.
- **관리자**: basic auth 기반 로그인(`admin` / `admin`), 상태별(발송대기/완료) 주문 목록, 복음 서약 여부 조회, 8자리 송장번호 발송처리(HTMX swap).

## 에러 로그
1. **better-sqlite3 설치 오류**: Node v24 Windows 환경에서 C++20 관련 컴파일 에러 발생. `@libsql/client`로 변경하여 패키지 설치 해결.
2. **TypeScript 빌드 오류**: JSX HTML attributes (`method="POST"`, `maxlength="8"`) 타입 오류 및 `Bible` 타입 정의 누락 발생. `method="post"`, `maxLength={8}`, `Bible` interface export 등으로 타입 명세 보정하여 빌드 패스.
3. **Vitest 테스트 충돌 오류**: TS 파일과 compiled JS 파일이 빌드 후 `tests/`에 공존하여 테스트 병렬 처리 중 `SQLITE_BUSY` 데이터베이스 잠금 현상 발생. `tsconfig.json`에 `outDir: "dist"` 지정 및 빌드 산출물 클린업으로 해결.
4. **PowerShell 커맨드 체인 오류**: `&&` 연산자 해석 파서 에러 발생. `;` 연산자로 대체하여 스크립트 실행 완료.
