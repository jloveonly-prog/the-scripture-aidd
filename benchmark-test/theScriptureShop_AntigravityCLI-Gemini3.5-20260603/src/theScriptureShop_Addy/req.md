# 프로젝트 개요
성경(KJV, NIV, 헬라어, 히브리어 등)을 무료로 배포하는 비회원 전용 쇼핑몰.

# 상세 요구사항

## 1. 상품 및 카탈로그
- 회원가입 기능은 없음.
- 상품(성경)은 DB에 미리 10개가 등록되어 있음(Seed 데이터).
- 메인 화면에서 이 10개의 성경 목록(표지, 번역본 이름, 설명)을 카드 형태로 보여줌.

## 2. 장바구니 (Cart)
- 원하는 성경을 장바구니에 담을 수 있음.
- 장바구니에서 수량 조절 및 삭제 가능.
- 가격은 없으므로 총액 계산은 생략.

## 3. 신앙 고백 및 주문 프로세스
- 장바구니에서 [주문하기] 클릭 시 주소 입력 폼 제공.
- 일반적인 결제 수단(PG, 무통장)은 없음.
- **주문 완료 조건 (핵심 로직):**
  주문 폼 하단에 아래 내용에 대한 체크박스와 `[믿는다]` 버튼이 존재함.
  > "예수님을 나의 구원자로 믿고, 내가 죄인인 것과 하나님이신 예수님이 내 죄들을 대신해 피 흘려 죽고 장사되시고 부활한 것을 믿고 받아들입니다."
- 체크 및 버튼 클릭 시 주문이 완료되며 고유 **'주문번호'** 가 화면에 표시됨.

## 4. 비회원 배송 조회
- 메인 화면 상단에 [배송 조회] 버튼 제공.
- 발급받은 '주문번호'를 입력하면 자신의 주문 내역과 **송장번호**를 확인할 수 있음.

## 5. 관리자 (Admin) 및 발송 처리
- `admin` / `admin` 계정으로 로그인하여 관리자 페이지 접근.
- 상태별(발송 대기 / 발송 완료) 주문 목록 확인.
- 주문 상세에서 해당 사용자가 '믿는다'라고 승인한 내역을 반드시 확인 가능해야 함.
- 관리자가 **송장번호 8자리(숫자)**를 입력하고 `[발송처리]`를 누르면 배송 처리가 완료되고 상태가 변경됨.
