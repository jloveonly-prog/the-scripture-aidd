# 🏛️ 아키텍처 및 인프라 설계

## 1. 시스템 아키텍처 개요
- **서버 구성**: 로컬 PC
- **DB 서버 및 캐시 전략**: 로컬 SQLite 파일 기반
- **배포 환경**: 로컬 환경 구동

## 2. 폴더 구조 판단
- 채택 구조: 통합 허용
- 판단 근거: Hono + HTMX + Alpine.js 조합의 단순 SSR 구성이며, 화면이 2개(메인, 게시판)뿐이라 통합 관리가 유리함.
- 예상 최대 파일 줄 수: 200줄

## 3. 아키텍처 결정 체인
| 결정 사항 | 근거 REQ-ID | 왜 이 선택인가 | 이 결정이 만드는 제약 | Phase 3/4 영향 |
|:--|:--|:--|:--|:--|
| 로컬 PC 환경 배포 | NFR-003 | 사용자가 로컬에서만 구동되기를 원함 | 클라우드 배포 불가, 로컬 환경 세팅 필요 | 로컬에서 카메라 접근을 위해 localhost 띄워야 함 |
| SQLite 사용 | NFR-002 | 경량 RDBMS 요구사항 | 별도 DB 서버 구축 없음 | DB 파일 관리 필요 |
| Hono + HTMX | NFR-001 | 기술 스택 요구사항 | SPA 프레임워크 배제 | 서버 렌더링 + 부분 업데이트 패턴 적용 |
