# 📋 요구사항 명세서

## 1. 프로젝트 개요
- 프로젝트명: 구글 QR Code 스캔 및 게시판
- 버전: 1.0.0
- 작성일: 2026-05-29
- 상태: 초안 (Draft)

## 2. 목적 (Purpose)
- 구글 QR 코드를 스캔하여 그 내용을 실시간으로 화면에 띄우고, 내역을 게시판 형태로 관리하기 위함.

## 3. Spec 근거
- `hearing-들음/req.md` (원본 요구사항)

## 4. 기능 요구사항 (Functional Requirements)

| REQ-ID | 구분 | 기능 요약 | 우선순위 |
|:---|:---|:---|:---:|
| FR-001 | 스캔 | 카메라를 통해 QR 코드를 스캔한다. | 높음 |
| FR-002 | 표시 | 스캔된 QR 코드의 내용을 즉시 화면에 표시한다. | 높음 |
| FR-003 | 저장 | 스캔된 내용을 DB(SQLite)에 저장한다. | 높음 |
| FR-004 | 게시판 | 저장된 스캔 내역을 게시판 형태로 목록 조회한다. | 높음 |

## 5. 비기능 요구사항 (Non-Functional Requirements)

| REQ-ID | 구분 | 내용 |
|:---|:---|:---|
| NFR-001 | 기술스택 | Node.js (Hono), Hono JSX + HTMX + Alpine.js + Tailwind |
| NFR-002 | DB | SQLite 사용 |
| NFR-003 | 인프라 | 로컬 PC 환경 구동 |
| NFR-004 | 환경 | 브라우저 환경에서 카메라 접근 권한 필요 |

## 6. 범위 (Scope)
- **포함**: 웹 브라우저 기반 QR 스캔 기능, 스캔 결과 실시간 표시, 스캔 이력 저장 및 게시판 조회 기능
- **제외**: 로그인/회원가입 기능, 다중 사용자 권한 관리, 원격 서버 배포(로컬 PC 구동)

## 7. 제약 조건
- C-001: 외부 API 통신 없이 로컬 브라우저에서 QR 디코딩 혹은 라이브러리 사용
- C-002: 로컬 환경(Localhost)에서 구동해야 카메라 권한(HTTPS 또는 localhost)을 받을 수 있음

## 8. 완료 기준
- 카메라를 통해 QR 코드를 스캔하면 화면에 내용이 정상적으로 표시되는가?
- 스캔된 내역이 게시판에 목록으로 1개 이상 나타나는가?
- SQLite DB에 데이터가 정상 저장되는가?
