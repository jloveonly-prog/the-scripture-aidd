## 3. 유스케이스 상세

### UC-001: QR 코드 스캔 및 표시
| 항목 | 내용 |
|:---|:---|
| UC-ID | UC-001 |
| 유스케이스명 | QR 코드 스캔 및 표시 |
| 행위자 | 사용자 |
| 연결 REQ | FR-001, FR-002, FR-003 |
| 전제 조건 | 사용자가 카메라 접근 권한을 허용해야 함 |
| 사후 조건 | 스캔된 내용이 화면에 표시되고 DB에 저장됨 |

**정상 경로:**
1. 사용자가 홈페이지에 접속한다.
2. 시스템이 카메라 화면을 표시한다.
3. 사용자가 QR 코드를 스캔한다.
4. 시스템이 QR 코드를 해독하여 화면에 내용을 표시한다.
5. 시스템이 해독된 내용을 DB에 저장한다.

**예외 경로:**
- E1. 사용자가 카메라 권한을 거부함 → 시스템이 "카메라 권한이 필요합니다" 메시지 표시.
- E2. QR 코드 인식 실패 → 시스템이 재스캔 대기 유지.

### UC-002: 게시판 내역 조회
| 항목 | 내용 |
|:---|:---|
| UC-ID | UC-002 |
| 유스케이스명 | 게시판 내역 조회 |
| 행위자 | 사용자 |
| 연결 REQ | FR-004 |
| 전제 조건 | 게시판 페이지에 접속 |
| 사후 조건 | 저장된 QR 스캔 이력이 화면에 표시됨 |

**정상 경로:**
1. 사용자가 게시판 메뉴/페이지로 이동한다.
2. 시스템이 DB에서 스캔 이력을 조회한다.
3. 시스템이 조회된 이력을 목록으로 화면에 표시한다.

**대안 경로:**
- 3a. 조회된 이력이 없으면 → 시스템이 "스캔된 내역이 없습니다" 메시지 표시.
