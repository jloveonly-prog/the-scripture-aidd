# 🎨 디자인 시스템 (Design Vision)

## 1. 디자인 원칙
- **야곱의 우물 원칙**: 스캔 결과가 즉시 보이고, 스캔 대기 상태로 자연스럽게 전환
- **게슈탈트 인지 원칙**: 유사한 정보(스캔 목록)는 리스트 형태로 근접 배치
- **반응형 설계**: 모바일 카메라 세로 모드 대응, 데스크톱 가로 모드 대응

## 2. 컬러 팔레트
- Primary: Tailwind 기본 파란색 (`bg-blue-600`) - 스캔 시작 버튼 등
- Secondary: Tailwind 기본 회색 (`bg-gray-100`) - 배경
- Text: 어두운 회색 (`text-gray-800`) - 가독성 확보
- Success: 녹색 (`text-green-600`) - 스캔 성공 알림

## 3. 타이포그래피
- 기본 폰트: 시스템 기본 폰트 (sans-serif)
- 제목: `text-2xl font-bold`
- 본문: `text-base`

## 4. 공통 컴포넌트
- **Header**: 로고 및 네비게이션 (홈, 게시판)
- **Button**: 버튼 공통 스타일
- **Card**: 스캔 결과 표시 컨테이너
