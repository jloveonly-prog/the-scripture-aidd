## 2. 화면 상세

### SCR-001: 홈(카메라 스캔) 화면
- **레이아웃**: 
  - 상단: 헤더 (네비게이션: 홈, 게시판)
  - 중앙: 카메라 영상 영역 (video 태그)
  - 하단: 최근 스캔된 결과 표시 영역 및 스캔 상태 표시
- **인터랙션**: 
  - 카메라 권한 요청 수락 후 비디오 스트리밍 시작
  - QR 코드가 인식되면 녹색 테두리 또는 알림음 (성공 피드백)
  - 인식 후 백엔드로 내용 POST, 화면 하단에 인식된 내용 표시 (HTMX 부분 업데이트)

### SCR-002: 스캔 게시판 화면
- **레이아웃**:
  - 상단: 헤더 (네비게이션: 홈, 게시판)
  - 중앙: 스캔 내역 리스트 (테이블 또는 카드 리스트 형태)
- **인터랙션**:
  - 페이지 로드 시 DB에서 전체 스캔 이력을 시간순(내림차순)으로 조회하여 표시
