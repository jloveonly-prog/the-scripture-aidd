# 📜 개발 계명 (Dev Guide)

## 1. HTTP 앱 인스턴스 Export
- 파일: `src/index.tsx`
- 방식: `export default app`을 사용하여 테스트 환경에서 인스턴스를 가져올 수 있도록 한다.

## 2. 계층 분리 원칙
- 채택: 통합 구조 (단일 파일)
- 파일: `src/index.tsx`
- 이유: 전체 화면이 2개(메인, 게시판)이며 예상 줄 수가 250줄 이내이므로 Hono JSX를 활용하여 라우팅과 렌더링을 한 파일에 작성하여도 단일 앱 책임을 초과하지 않는다.

## 3. 예외 처리
- 모든 API 엔드포인트(`app.post`, `app.get`)에 `try-catch`를 적용하고 오류 발생 시 500 에러를 반환한다.
