## 2. 디자인 시스템

## 4. 인터랙션 디자인

| 이벤트 | 동작 | 피드백 |
|:---|:---|:---|
| 버튼 호버 | 배경색 어두워짐 | transition 150ms |
| 목록 행 호버 | 배경색 연한 하이라이트 | bg-gray-50 |
| 폼 제출 | 서버 전송 후 리다이렉트 | 버튼 비활성화 중 표시 |
| 삭제 클릭 | confirm 대화상자 | "정말 삭제하시겠습니까?" |
| 빈 입력 제출 | HTML required + 서버 검증 | 에러 메시지 표시 |

## 6. 접근성 (Accessibility)

| 항목 | 적용 |
|:---|:---|
| 색상 대비 | 4.5:1 이상 (WCAG AA) — #1E293B on #F8FAFC = 15.4:1 ✅ |
| 키보드 네비게이션 | Tab으로 모든 인터랙티브 요소 접근 가능 |
| 폼 레이블 | 모든 input에 label 연결 |
| 버튼 | 의미 있는 텍스트 (아이콘만 사용 금지) |
| 시맨틱 HTML | header, main, nav, article 사용 |
