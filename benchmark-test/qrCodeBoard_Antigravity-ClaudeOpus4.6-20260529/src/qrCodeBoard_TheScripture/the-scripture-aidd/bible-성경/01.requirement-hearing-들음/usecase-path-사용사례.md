## 유스케이스 상세

### UC-001: QR 코드 스캔으로 홈페이지 접속

| 항목 | 내용 |
|:---|:---|
| UC-ID | UC-001 |
| 유스케이스명 | QR 코드 스캔으로 홈페이지 접속 |
| 행위자 | ACT-001 (방문자) |
| 연결 REQ | REQ-001, REQ-003, FR-001 |
| 전제 조건 | 사용자가 QR 코드가 인쇄/표시된 매체를 볼 수 있음 |
| 사후 조건 | 브라우저에 홈페이지가 표시됨 |

**정상 경로 (Main Path — 좁은 길):**
1. 사용자가 스마트폰의 구글 렌즈/카메라 앱으로 QR 코드를 스캔한다
2. QR 코드에 인코딩된 URL이 인식된다
3. 브라우저가 해당 URL로 이동한다
4. 시스템이 홈페이지를 표시한다
5. 홈페이지에서 게시판으로의 네비게이션이 표시된다

**대안 경로 (Alternate Path — 다른 길):**
- 3a. 사용자가 URL을 브라우저에 직접 입력하여 접속한다 → 4단계로 이동

**예외 경로 (Exception Path — 넓은 길로 빠지는 경우):**
- E1. QR 코드 인식 실패 → 사용자가 재스캔하거나 URL 직접 입력
- E2. 서버 미구동 → 브라우저에 연결 실패 화면 표시

### UC-002: 게시판 글 목록 조회

| 항목 | 내용 |
|:---|:---|
| UC-ID | UC-002 |
| 유스케이스명 | 게시판 글 목록 조회 |
| 행위자 | ACT-001 (방문자) |
| 연결 REQ | REQ-002, FR-002 |
| 전제 조건 | 사용자가 홈페이지에 접속한 상태 |
| 사후 조건 | 게시판 글 목록이 화면에 표시됨 |

**정상 경로 (Main Path — 좁은 길):**
1. 사용자가 홈페이지에서 게시판 메뉴를 클릭한다
2. 시스템이 SQLite에서 게시글 목록을 조회한다
3. 시스템이 게시글 목록(번호, 제목, 작성일)을 표시한다

**대안 경로 (Alternate Path — 다른 길):**
- 없음

**예외 경로 (Exception Path — 넓은 길로 빠지는 경우):**
- E1. 게시글이 0건인 경우 → "등록된 게시글이 없습니다" 메시지 표시
- E2. DB 조회 실패 → "데이터를 불러올 수 없습니다" 에러 표시

### UC-004: 게시판 글 작성

| 항목 | 내용 |
|:---|:---|
| UC-ID | UC-004 |
| 유스케이스명 | 게시판 글 작성 |
| 행위자 | ACT-001 (방문자) |
| 연결 REQ | REQ-002, FR-004 |
| 전제 조건 | 사용자가 게시판 화면에 있음 |
| 사후 조건 | 새 게시글이 SQLite에 저장되고 목록에 표시됨 |

**정상 경로 (Main Path — 좁은 길):**
1. 사용자가 "글쓰기" 버튼을 클릭한다
2. 시스템이 글 작성 폼(제목, 내용)을 표시한다
3. 사용자가 제목과 내용을 입력한다
4. 사용자가 "저장" 버튼을 클릭한다
5. 시스템이 입력값을 검증한다
6. 시스템이 게시글을 SQLite에 저장한다
7. 시스템이 게시판 목록 페이지로 이동하며 새 글이 표시된다

**대안 경로 (Alternate Path — 다른 길):**
- 4a. 사용자가 "취소" 버튼 클릭 → 목록 페이지로 이동

**예외 경로 (Exception Path — 넓은 길로 빠지는 경우):**
- E1. 제목이 비어있음 → "제목을 입력하세요" 메시지 표시
- E2. 내용이 비어있음 → "내용을 입력하세요" 메시지 표시
- E3. DB 저장 실패 → "저장에 실패했습니다. 다시 시도해주세요" 에러 표시

### UC-005: 게시판 글 수정

| 항목 | 내용 |
|:---|:---|
| UC-ID | UC-005 |
| 유스케이스명 | 게시판 글 수정 |

| 사후 조건 | 수정된 게시글이 SQLite에 반영됨 |

**정상 경로 (Main Path — 좁은 길):**
1. 사용자가 게시글 상세 화면에서 "수정" 버튼을 클릭한다

3. 사용자가 내용을 수정한다
4. 사용자가 "저장" 버튼을 클릭한다
5. 시스템이 입력값을 검증한다
6. 시스템이 게시글을 SQLite에서 업데이트한다
7. 시스템이 게시글 상세 화면으로 이동하며 수정된 내용이 표시된다

**대안 경로 (Alternate Path — 다른 길):**
- 4a. 사용자가 "취소" 버튼 클릭 → 게시글 상세 페이지로 이동

**예외 경로 (Exception Path — 넓은 길로 빠지는 경우):**
- E1. 제목이 비어있음 → "제목을 입력하세요" 메시지 표시
- E2. 내용이 비어있음 → "내용을 입력하세요" 메시지 표시
- E3. DB 업데이트 실패 → "수정에 실패했습니다. 다시 시도해주세요" 에러 표시
