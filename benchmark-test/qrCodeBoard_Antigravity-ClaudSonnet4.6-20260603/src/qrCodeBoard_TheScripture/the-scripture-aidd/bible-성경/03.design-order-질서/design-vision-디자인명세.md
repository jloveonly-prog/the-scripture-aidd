## 2. 디자인 시스템

## 4. 인터랙션 디자인

| 요소 | 이벤트 | 동작 |
|:---|:---|:---|
| QR 스캐너 | QR 감지 성공 | 스캔 결과 영역에 즉시 표시, 카메라 테두리 녹색 변경 |
| QR 스캐너 | 카메라 오류 | 에러 메시지 표시, 재시도 안내 |
| 스캔 결과 URL | 클릭 | 새 탭에서 URL 열기 |
| 글 작성 버튼 | 클릭 | /board/new로 이동 |
| 게시글 카드 | 클릭 | /board/:id로 이동 |
| 등록 버튼 | 클릭 | POST /board, 성공 시 /board 리다이렉트 |
| 취소 버튼 | 클릭 | /board로 이동 |
| 목록으로 링크 | 클릭 | /board로 이동 |

### 로딩/에러/빈 상태

| 상태 | 화면 표현 |
|:---|:---|
| 카메라 로딩 | "카메라를 불러오는 중..." 텍스트 + 스피너 |
| 카메라 권한 거부 | "카메라 접근 권한이 필요합니다" 경고 아이콘 |
| 게시글 없음 | "등록된 게시글이 없습니다" 회색 텍스트 |
| 폼 에러 | 빨간색 에러 메시지 박스 |
| 게시글 없음 (404) | "게시글을 찾을 수 없습니다" + 목록으로 링크 |

## 6. 접근성 (WCAG 2.1 AA)

| 항목 | 구현 |
|:---|:---|
| 색상 대비 | Primary #4F46E5 on White: 7.4:1 ✅ |
| 키보드 네비게이션 | Tab 키로 모든 인터랙티브 요소 접근 가능 |
| 폼 레이블 | `<label for="...">` 연결 |
| 이미지 대체 텍스트 | alt 속성 적용 |
| 포커스 표시 | focus:ring-2 ring-indigo-500 |
| 에러 안내 | role="alert" aria-live="polite" |
