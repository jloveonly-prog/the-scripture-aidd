## 유스케이스 상세

### UC-001: 홈페이지 접속 및 QR 스캐너 열기

| 항목 | 내용 |
|:---|:---|
| UC-ID | UC-001 |
| 유스케이스명 | 홈페이지 접속 및 QR 스캐너 열기 |
| 행위자 | ACT-001 (방문자) |
| 연결 REQ | REQ-003, FR-003 |
| 전제 조건 | 서버가 포트 4000으로 구동 중 |
| 사후 조건 | 홈페이지 메인 화면이 표시되고 QR 스캐너 UI가 준비됨 |

**정상 경로 (Main Path — 좁은 길):**
1. 사용자가 브라우저에서 `http://localhost:4000`에 접속한다
2. 시스템이 홈페이지 메인 화면을 반환한다
3. 화면에 QR 스캐너 UI(카메라 뷰파인더)가 표시된다
4. 시스템이 카메라 접근 권한을 요청한다

**대안 경로 (Alternate Path):**
- 없음

**예외 경로 (Exception Path):**
- E1. 카메라 권한 거부 → "카메라 접근 권한이 필요합니다" 안내 메시지 표시
- E2. 카메라 장치 없음 → "카메라를 찾을 수 없습니다" 메시지 표시

---

### UC-002: QR 코드 스캔 및 결과 표시

| 항목 | 내용 |
|:---|:---|
| UC-ID | UC-002 |
| 유스케이스명 | QR 코드 스캔 및 결과 표시 |
| 행위자 | ACT-001 (방문자) |
| 연결 REQ | REQ-001, REQ-002, FR-001, FR-002 |
| 전제 조건 | 홈페이지 접속 완료, 카메라 권한 허용됨 |
| 사후 조건 | QR 코드 스캔 결과(URL 또는 텍스트)가 화면에 표시됨 |

**정상 경로 (Main Path — 좁은 길):**
1. 사용자가 카메라 뷰파인더에 QR 코드를 가져다 댄다
2. 시스템이 카메라 스트림에서 QR 코드를 실시간으로 감지한다
3. QR 코드 인식 성공 시 시스템이 스캔된 데이터(URL/텍스트)를 즉시 화면에 표시한다
4. 스캔 결과가 URL인 경우 클릭 가능한 링크로 표시된다

**대안 경로 (Alternate Path):**
- 4a. 스캔 결과가 URL이 아닌 텍스트인 경우 → 텍스트로 표시

**예외 경로 (Exception Path):**
- E1. QR 코드 인식 실패 (화질 불량, 거리 문제) → 스캐너 계속 동작, 사용자가 위치 조정
- E2. 카메라 스트림 중단 → "카메라 연결이 끊겼습니다. 새로고침하세요" 메시지

### UC-003: 게시판 글 목록 조회

| 항목 | 내용 |
|:---|:---|
| UC-ID | UC-003 |
| 유스케이스명 | 게시판 글 목록 조회 |
| 행위자 | ACT-001 (방문자) |
| 연결 REQ | REQ-004, FR-004 |
| 전제 조건 | 서버 구동 중 |
| 사후 조건 | 게시판 글 목록이 화면에 표시됨 |

**정상 경로 (Main Path — 좁은 길):**
1. 사용자가 게시판 메뉴를 클릭한다
2. 시스템이 SQLite DB에서 게시글 목록을 조회한다
3. 시스템이 글 목록(제목, 작성일 등)을 표시한다

**대안 경로 (Alternate Path):**
- 없음

**예외 경로 (Exception Path):**
- E1. 게시글 없음 → "등록된 게시글이 없습니다" 메시지 표시
- E2. DB 조회 오류 → "서버 오류가 발생했습니다" 메시지 표시

### UC-004: 게시판 글 상세 조회

| 항목 | 내용 |
|:---|:---|
| UC-ID | UC-004 |
| 유스케이스명 | 게시판 글 상세 조회 |
| 행위자 | ACT-001 (방문자) |
| 연결 REQ | REQ-006, FR-006 |
| 전제 조건 | 게시판 목록 화면에 있음 |
| 사후 조건 | 선택한 게시글의 상세 내용이 표시됨 |

**정상 경로 (Main Path — 좁은 길):**
1. 사용자가 게시글 목록에서 글 제목을 클릭한다
2. 시스템이 해당 글의 상세 내용을 DB에서 조회한다
3. 시스템이 제목, 내용, 작성일을 화면에 표시한다

**대안 경로 (Alternate Path):**
- 없음

**예외 경로 (Exception Path):**
- E1. 존재하지 않는 글 ID 접근 → "게시글을 찾을 수 없습니다" 메시지 + 목록으로 이동

### UC-005: 게시판 글 작성

| 항목 | 내용 |
|:---|:---|
| UC-ID | UC-005 |
| 유스케이스명 | 게시판 글 작성 |
| 행위자 | ACT-001 (방문자) |
| 연결 REQ | REQ-005, FR-005 |
| 전제 조건 | 게시판 화면에 접근 가능 |
| 사후 조건 | 새 게시글이 DB에 저장되고 목록에 표시됨 |

**정상 경로 (Main Path — 좁은 길):**
1. 사용자가 "글 작성" 버튼을 클릭한다
2. 시스템이 글 작성 폼을 표시한다
3. 사용자가 제목과 내용을 입력한다
4. 사용자가 "등록" 버튼을 클릭한다
5. 시스템이 입력 데이터를 SQLite DB에 저장한다
6. 시스템이 게시판 목록 화면으로 리다이렉트한다

**대안 경로 (Alternate Path):**
- 없음

**예외 경로 (Exception Path):**
- E1. 제목 또는 내용 미입력 → "제목과 내용을 입력해주세요" 유효성 검사 메시지
- E2. DB 저장 오류 → "저장에 실패했습니다. 다시 시도해주세요" 메시지
